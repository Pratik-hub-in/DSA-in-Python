# Linked List

The **Linked List** folder contains Python implementations of fundamental linked list operations and algorithms.

A Linked List is a linear data structure where elements are stored in nodes. Each node contains data and a reference to the next node, making insertions and deletions efficient.

---

## 📚 Topics Covered

- Singly Linked List
- Insertion
- Deletion
- Search
- Reverse Linked List
- Find Middle Node
- Detect Cycle
- Merge Two Sorted Lists
- Remove Nth Node From End
- Doubly Linked List
- Circular Linked List

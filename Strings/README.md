# Strings

The **Strings** folder contains Python implementations of fundamental string operations and algorithms.

Strings are one of the most commonly used data structures in programming. Understanding string manipulation is essential for solving coding interview problems and building real-world applications.

---

## 📚 Topics Covered

- String Traversal
- String Length
- Reverse String
- Palindrome Check
- Character Frequency
- Remove Whitespace
- Count Vowels & Consonants
- Anagram Check
- Longest Common Prefix
- String Compression
- Sliding Window Technique
- Two Pointer Technique
